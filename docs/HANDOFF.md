## Gotchas learned

- **Never run `shopify app dev --verbose` for long:** Babel debug logging fills the heap and the CLI crashes after ~12 min ("JavaScript heap out of memory"); the app then looks broken (no save bar, spinners). Use it only to read one error, then restart without it.
- **Don't install the production app on the dev store.** Its discount, checkout rule, theme embed and `/apps/perks` proxy clash with the dev app's. If an app is installed while another holds `/apps/perks`, Shopify gives it `/apps/perks-1`; the code links to `/apps/perks`, so fix it in Settings → Apps → <app> → App Proxy URL → Customize URL.
- `s-clickable href` reloads the app iframe without the embedded params (404). Navigate with `useNavigate()` in `onClick`.
- Native `s-select` dropdowns and tooltips inside the app iframe can't be driven by browser automation; test those by hand.
- Admin blocks: merchants add them with "+ Block" on the resource page and must pin them, or they disappear on reload. Keep them short; the admin warns when a block is too tall.
- The CLI regenerates `extensions/*/shopify.d.ts` (with `@ts-ignore`) on every dev run; lint skips that file.
- Test card payments on the dev store (Bogus gateway, card `1`) are placed by Zeeshan, not the agent.
- Theme embed script must stay under 10 KB; no `{` or `}` inside `{{ }}` in Liquid (tests guard both).
- The CLI edits `shopify.app.production.toml` on deploy; regenerate it with `node scripts/make-prod-config.mjs` instead of hand-merging.
- Scope changes: update Railway `SCOPES` before merging.
- App Bridge save bar must be hidden before leaving a page (`useSaveBar`).
- Shopify app discounts don't change product page prices; the theme embed shows the employee price instead.
- `s-section` has no box of its own (display: contents): to scroll to one, put the id on a wrapping `div`.
- App Bridge drops `#hash` links inside the app: use a query parameter (`?section=perks-page`).
- `s-text` ignores `type="strong"` and `tone` inside some cards; use a plain styled element when it must stand out.
- Polaris web components can't put chips inside a text field; `DomainChips` is a lookalike field.
- After a Prisma migration, restart `shopify app dev`: the running server keeps the old client and saves fail.
- Theme embed block types are `shopify://apps/<app-name-slug>/blocks/employee-mode/<uuid>`: dev is `perks`, production `employee-perks`. `embedEnabled` matches on the slug.
