## Gotchas learned

- **Billing:** the plan page is `https://admin.shopify.com/store/{store}/charges/tofo-perks/pricing_plans`. A wrong `SHOPIFY_APP_HANDLE` gives a 404 there. Shopify shows every public plan to every store (we can't hide Basic from Grow stores); plan descriptions must say who each plan is for. Billing period values are `ANNUAL` / `EVERY_30_DAYS`. Plans are free on dev stores. Shopify sends no billing webhooks; coming back from the plan page carries `?plan_handle=`, which makes the app re-check at once.
- **App Store listing rules:** no prices outside Pricing, no statistics, "best/only", reviews or Shopify logo in images or text. No store-address install box on the site (rule 2.3.1).
- Production config changes (Railway variables) and force pushes are done by Zeeshan; the agent's sandbox blocks them.
- **Never run `shopify app dev --verbose` for long:** Babel debug logging fills the heap and the CLI crashes after ~12 min.
- **Don't install the production app on `perks-frtekwck`.** Its discount, checkout rule, theme embed and `/apps/perks` proxy clash with the dev app's. If an app is installed while another holds `/apps/perks`, Shopify gives it `/apps/perks-1`; fix it in Settings → Apps → <app> → App Proxy URL → Customize URL.
- `s-clickable href` reloads the app iframe without the embedded params (404). Navigate with `useNavigate()` in `onClick`.
- `s-grid` responsive columns need `<s-query-container>` (in `app.tsx`) and `"@container (inline-size > 600px) A, B"`.
- Native `s-select` dropdowns and tooltips inside the app iframe can't be driven by browser automation; test those by hand.
- Admin blocks: merchants add them with "+ Block" on the resource page and must pin them.
- The CLI regenerates `extensions/*/shopify.d.ts` (with `@ts-ignore`) on every dev run; lint skips that file.
- Test card payments (Bogus gateway, card `1`) are placed by Zeeshan, not the agent.
- Theme embed script must stay under 10 KB; no `{` or `}` inside `{{ }}` in Liquid (tests guard both).
- The CLI edits `shopify.app.production.toml` on deploy; regenerate it with `node scripts/make-prod-config.mjs` instead of hand-merging.
- Scope changes: update Railway `SCOPES` before merging.
- App Bridge save bar must be hidden before leaving a page (`useSaveBar`).
- Shopify app discounts don't change product page prices; the theme embed shows the employee price instead.
- `s-section` has no box of its own (display: contents): to scroll to one, put the id on a wrapping `div`.
- App Bridge drops `#hash` links inside the app: use a query parameter (`?section=perks-page`).
- After a Prisma migration, restart `shopify app dev`: the running server keeps the old client and saves fail.
- Theme embed block types are `shopify://apps/<app-name-slug>/blocks/employee-mode/<uuid>`: dev is `perks`, production `employee-perks`.
